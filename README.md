# WhatsApp Chat Analyzer

Analyses a WhatsApp group chat export: message counts per person, activity by hour and emoji ussage.

## Files
- `TextFileGenerator.ipynb`: generates a synthetic chat so no real data is needed
- `Analyzer.ipynb`: parses and analyses the chat
- `sample_chat.txt`: sample synthetic chat

## How to run
1. `pip install pandas matplotlib pandas emoji  plotly.express re ` 
2. Run `TextFileGenerator.ipynb` (optional, the sample is already included)
3. Run `Analyzer.ipynb`

## Note
All data is synthetic. No real conversations are included.# whatsapp-chat-analyzer
